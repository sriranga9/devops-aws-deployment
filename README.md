# DevOps CI/CD Lab 🚀

This repository contains hands-on DevOps projects demonstrating real-world CI/CD pipelines using Jenkins, Docker, Kubernetes, GitHub Actions, and AWS.

## 📂 Repository Structure

- projects/ → Individual DevOps projects
- jenkins/ → Pipelines & shared libraries
- kubernetes/ → Deployment manifests
- docs/ → Notes and interview questions

## 🔥 Projects

- multi-stage-pipeline → Jenkins multi-stage pipeline
- flask-ci-cd-pipeline → Flask + Docker CI/CD

## ⚙️ Tech Stack

- Jenkins
- Docker
- Kubernetes
- AWS
- GitHub Actions

## 🚀 Goal

To build production-level DevOps pipelines and showcase hands-on skills.
